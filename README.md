How can you share state between components in react...(
    React-এ একাধিক কম্পোনেন্টের মধ্যে state শেয়ার করার উপায়গুলো হলো:
. Lift State Up – common parent component এ state রেখে props এর মাধ্যমে child-এ পাঠানো যায় 
. Context API – props না পাঠিয়ে একাধিক কম্পোনেন্টে state শেয়ার করা যায় 
. Global State Management  বড় অ্যাপের জন্য global store ব্যবহার।

. Custom Hook + Context – একই logic ও state একাধিক কম্পোনেন্টে ব্যবহার করার জন্য .....
)
